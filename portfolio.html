Privacy design

No holdings stored in public GitHub

The Excel workbook is read locally by your browser. Parsed data is stored only in this browser's local storage so the page can reopen without another upload.

  • No Angel One credentials are requested.
  • No PAN, client code or source-statement filenames are retained.
  • Clearing browser data removes the locally stored portfolio snapshot.

SmartAPI read-only collector

A private backend can later update live holdings, trade book and market quotes while publishing only sanitised portfolio calculations to this interface.

  • No order-placement, modification, cancellation or GTT functions.
  • Intraday snapshots will produce portfolio day high and low.
  • New buys and sells will appear automatically.
